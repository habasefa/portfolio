Personalized study agent

Built Magnus’s study counselor as a generative recommendation system. It uses a student’s profile and study performance—subject accuracy, weakest topics, and streaks—to help decide what to study next and turn that advice into a concrete schedule.

  • Student profile and performance tools give the agent context for recommendations based on the student’s progress.

  • Profile access and plan writes are feature-gated; the counselor can also advise from the conversation when those tools are disabled.

Liqawnt Labs

In development

Amharic text-to-speech adaptation, from corpus preparation to evaluation.

Liqawnt Labs is a low-resource audio startup working on tokenization, TTS, and ASR. Current work includes fine-tuning Pocket TTS on 200 hours of Amharic speech. Earlier work uses a pretrained VITS checkpoint as a baseline. The pipeline includes Amharic text normalization and romanization, audio conditioning, dataset preparation, fine-tuning, synthesis, and evaluation.

Amharic adaptation and evaluation

  • Fine-tuning Pocket TTS on a 200-hour Amharic speech dataset.
  • Prepared an internal benchmark using word error rate (WER) and native-speaker ratings.
  • Ran reinforcement learning experiments targeting intonation, prosody, and Amharic accent fidelity.

Earlier VITS pipeline work

  • Text preprocessing for Ge’ez script, numeral expansion, and homophone normalization, shared between training and inference.
  • Audio resampling, silence trimming, loudness normalization, and quality checks before writing dataset manifests.
  • A PyTorch training path for the text encoder, flow, and duration predictor, with monotonic alignment search. The posterior encoder and waveform decoder remain frozen.
  • Evaluation code for spectral distortion, pitch, voicing, and duration. Results depend on the reference speaker and are interpreted alongside listening tests.

Pocket TTS fine-tuning is in progress. ASR is part of the startup’s research scope; no completed ASR system is claimed. The Amharic evaluation benchmark is internal. Earlier VITS decoder freezing limits voice adaptation.

Learning project · 2026

myTorch

Open source

A small implementation of neural-network fundamentals in Python.

A micrograd-style scalar autograd engine records a computation graph and propagates gradients in reverse topological order. Neuron, layer, and MLP classes use the engine; an SGD optimizer updates parameters.

  • Arithmetic operators and ReLU with accumulated gradients, including reused operands and multiple paths through the graph.
  • Unit tests for forward operations, graph structure, and backward propagation.
  • A byte-level BPE tokenizer with pair-frequency training, ordered merge replay, encoding, and decoding.

An educational implementation, not a tensor framework or a replacement for PyTorch.

Biomedical engineering thesis · Addis Ababa University · 2024

UlcerGuard

Prototype

A wearable-to-clinician telemetry pipeline for monitoring foot-pressure distribution.

Built as a biomedical engineering thesis: Arduino-based pressure sensors in wearable footwear send measurements to a React Native app over Bluetooth. The phone displays readings and relays them to a backend for live clinician visualization and review.

  • Sensor acquisition: Read timestamped pressure measurements from toe, heel, and metatarsal regions; parse the sensor stream on the phone.
  • Mobile monitoring: Visualize pressure distribution, review historical logs, and surface pressure-imbalance alerts to the wearer.
  • Streaming backend: Forward readings through Socket.IO to a Node.js/Express service, which broadcasts updates to the clinician dashboard.
  • Clinician interface: Display live sensor readings and visualizations in a React dashboard to support inspection of pressure patterns.

Arduino · Bluetooth · React Native · TypeScript · Node.js/Express · Socket.IO · React
